Hephaestus Startup Guide (Canonical)

This document defines the only supported startup path for the repository.

1. Canonical entrypoint
- Use start.ps1 from the repository root.

PowerShell:
.\start.ps1

2. What start.ps1 does
- Resolves npm from PATH.
- Runs npm run cli with any passed arguments.
- Opens the numbered operator control plane.

3. Equivalent direct command
- npm run cli

4. Service-level commands (development and verification)
- npm run start
- npm run start:once
- npm run ui

5. Deprecated startup methods
- Legacy startup scripts were removed from the canonical flow and should not be used.
- If external notes mention older launcher names, treat them as historical references only.

6. Control plane defaults
- UI defaults to http://127.0.0.1:4180/
- For token-gated access, append ?token=<token> when required by your local config.

7. Troubleshooting
- If startup fails, run npm run build and npm run preflight.
- Confirm Node version satisfies package.json engines (>= 22.5.0).
- Confirm npm is available in PATH.
