# Hephaestus Papers Library

This directory stores lawful local copies of research papers that are repeatedly useful to Hephaestus design work.

## Rules

- Store a PDF only when it is open access or locally licensed.
- Keep the matching note in sources/notes/ even when the PDF exists.
- Do not place unauthorized copyrighted copies here.
- Prefer a small active set that directly informs the blueprint.
