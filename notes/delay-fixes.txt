Hephaestus Delay Critique Fix Report
Date: 2026-06-02
Scope: processing-rate and queue-delay critiques
Source baseline: notes/critiques1.txt (functional critiques + delay audit)

Summary
Applied delay-focused remediations to reduce queue idle time, redispatch churn, and shell-call overhead in context gathering. Existing resolved critiques were revalidated, and unresolved non-delay architecture items are listed as follow-up.

Implemented Fixes

1) Redispatch churn now uses adaptive backoff with faster first retry
- File: src/task-store.ts
- Changes:
  - Added config options:
    - redispatchPendingMaxAfterMs
    - redispatchBackoffMultiplier
  - Added env-driven defaults:
    - TICKET_POLLING_INTERVAL_MS default 500
    - REDISPATCH_PENDING_AFTER_MS default 15000
    - REDISPATCH_PENDING_MAX_AFTER_MS default 120000
    - REDISPATCH_BACKOFF_MULTIPLIER default 1.5
    - STALE_RECOVERY_MIN_AGE_MS default lowered to 60000
  - Added per-ticket redispatch delay state map:
    - pendingRedispatchDelayMs
  - Redispatch logic:
    - first pending redispatch after 15s (default)
    - subsequent pending redispatches back off by 1.5x up to 120s
    - delay state cleared when ticket leaves pending
- Critique addressed:
  - 3.6 Redispatch semantics can create repeated admission churn

2) Stage autopilot loops no longer default to 5-minute sleeps
- Files:
  - scripts/stage-a-autopilot-loop.ps1
  - scripts/stage-b-autopilot-loop.ps1
- Changes:
  - CycleIntervalSeconds default lowered from 300 to 60 for both Stage A and Stage B loop scripts
- Delay impact addressed:
  - reduced queue priming cadence gap from 5m to 1m by default

3) Context git status call switched to argument-vector execution
- File: src/runtime.ts
- Changes:
  - Replaced shell string execution of git status with execFile('git', ['status', '--short'])
- Critiques addressed:
  - 3.7 repeated best-effort shell calls per task (cache existed already; call is now shell-safe and still cached)

4) Environment documentation updated for tuning knobs
- File: .env.example
- Added:
  - TICKET_POLLING_INTERVAL_MS=500
  - REDISPATCH_PENDING_AFTER_MS=15000
  - REDISPATCH_PENDING_MAX_AFTER_MS=120000
  - REDISPATCH_BACKOFF_MULTIPLIER=1.5
  - STALE_RECOVERY_MIN_AGE_MS=60000
